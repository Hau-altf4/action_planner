# Báo cáo Overleaf

1. Tạo dự án trống trên Overleaf và tải toàn bộ thư mục này lên.
2. Chọn **XeLaTeX** trong `Menu -> Compiler`.
3. Mở `main.tex`, bổ sung MSSV Nguyễn Cao Hậu tại `\studentTwoId`.
4. Có thể tạo thư mục `images/` và thêm `logo-truong.png`, `dang-nhap.png`,
   `danh-sach-cong-viec.png`, `chinh-sua-cong-viec.png`.

Nếu chưa có ảnh, tài liệu vẫn biên dịch và hiển thị khung nhắc vị trí cần bổ sung.
